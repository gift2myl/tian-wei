# 陈郝之家 · tian & wei

清语风格住宅的交互式三维体验，使用 Blender 导出的完整 GLB 模型。支持鸟瞰、室内漫游、六种智能场景、灯光与窗帘调节，以及入户、人体感应、空气和漏水事件演示。

这些交互用于方案体验，不连接或控制真实家庭设备。模型为参考图和户型资料重建的设计模型，不能替代施工图。

## 运行与部署

使用 Node.js 22.18 或更新版本：

```sh
npm ci
npm run dev
```

```sh
npm run build
npm start
```

`npm run build` 先校验 TypeScript、模型完整性和智能场景行为，再生成 `dist/`。将仓库导入 Vercel 即可；根目录的 `vercel.json` 指定 Vite、安装命令和输出目录，无需服务端或环境密钥。

请通过 HTTP 服务打开页面，不要直接双击 HTML；模型和纹理需要浏览器正常加载。浏览器需支持 WebGL 2。

## 体验操作

- 鼠标拖动旋转，滚轮缩放；切换室内视角可开启漫游。
- 使用 WASD 或方向键移动，拖动观察方向。
- 场景按钮切换晨起、回家、观影、睡眠、夜起、离家；播放按钮演示整套场景。
- 设备页调节亮度、窗帘和幕布；自动化页模拟传感器事件。
- 点击模型物体查看名称，重置按钮恢复回家场景。

`public/assets/qingyu.glb` 包含 719 个网格与 10 张内嵌纹理；`model.json` 保存相机及交互映射，必须与模型配套发布。
