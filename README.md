# 清语 · Z-Link 空间体验

同一份 Blender 原模型导出为 GLB，保留米制尺寸与家具、木地板、帘体、设备、植物几何。GLB 为 728 个节点、719 个网格；未使用减面。五种主要程序材质烘焙为 Base Color / Normal PBR 贴图。实时 WebGL 与 Cycles 离线渲染光影不同，提供原始渲染对照。

## 使用

- 拖动旋转、滚轮缩放，点击物件查看名称；底部切换六个空间视角。
- 场景页切换晨起、回家、观影、睡眠、起夜、离家；点击播放体验 30 秒自动演示。
- 设备页实时调整分区灯光、日光、两组窗帘与投影幕。
- 感知页模拟入户、起夜有人、CO₂ 升高及漏水。漏水关闭模型中的水阀并显示告警；可清除告警或恢复默认。
- 脚印按钮进入漫游；先点击三维画面，再使用 WASD 移动、方向键转向。墙体具有简单碰撞检测。
- 渲染对照为静态图片，仅鸟瞰、客餐厅、主卧、细节提供。玄关和俯视为实时视角。

## 本地 HTML

`npm run build:html` 生成 `build/index.html` 和本地依赖资源。复制 `local-launcher/` 内容进入 `build/`，双击其中的 `启动清语网页.command`，或运行 `python3 serve.py`。启动器使用空闲本地端口，不需要联网、账号或 npm。需支持 WebGL 2 的现代浏览器和 Python 3。本地 HTTP 服务是浏览器读取 GLB 所需，不能用 file:// 直接双击 HTML。

开发：`npm run dev`。托管构建：`npm run build`。类型检查：`npx tsc --noEmit`。

## 边界

1:1 指网页相对于已交付 Blender 模型的几何与尺寸保持一致。原模型依据 PDF 重建，非现场实测或施工图；本版本不新增隐蔽结构的精度保证。智能控制为本地状态模拟，没有连接真实 Z-Link 设备。漏水与水阀联动为扩展示例。品牌产品名称沿用用户提供的方案资料，UI 不代表厂商官方软件。
